# Task 5 – Same Screen, Different Event-Handling Styles (currency converter)

Files
- `Converter.java` – style (d), lambda expression. Completed "Complete the Code" version.
- `ConverterVariants.java` – styles (a) frame implements ActionListener, (b) named inner class, (c) anonymous inner class. Each one also has the Enter key and a result dialog (Task 5.2).

Compile and run
```bash
cd Task05
javac Converter.java ConverterVariants.java
java Converter              # lambda version
java ConverterVariants a    # or b, or c
```
