# Task 2 – Hospital Outpatient Appointment Desk (design only)

Task 2 is a design task. Its deliverables are written in `../Assignment_Report.md`:
- 2.1 event table
- 2.2 component hierarchy
- 2.3 handler pseudocode (refresh doctor list; validate and book)
- 2.4 event trace and comparison with applet life cycle
- alternative analysis (database query per department change vs loaded map)

Supporting file
- `WindowTrace.java` – prints the window event order used in 2.4.
- `window_trace_output.txt` – output of that program.

Run the trace (needs a display):
```bash
javac WindowTrace.java
java WindowTrace
```
