# Task 3 – Campus Library Search Screen

File: `LibrarySearchScreen.java` (Swing). Layout: nested BorderLayout and FlowLayout panels, described in `../Assignment_Report.md` section 3.

Compile and run
```bash
cd Task03
javac LibrarySearchScreen.java
java LibrarySearchScreen
```
Try it: type "java" and press Search (or Enter), use Prev and Next, press Reserve and enter an item number.

Resizing test (Task 3.4): `screenshots/` holds the three sizes (T3_1 default, T3_2 560x420, T3_3 1000x700). The report records what each region did.
